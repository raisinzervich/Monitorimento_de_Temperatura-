# Projeto-estruturas-de-repetição
## 🌡️ Sistema de Monitoramento Industrial de Temperatura em C

Projeto desenvolvido em linguagem C para simular um sistema de monitoramento industrial de temperatura, aplicando conceitos de **estruturas de repetição, estruturas condicionais e validação de dados**.

### ⚙️ Funcionamento

* Solicita ao usuário um limite de temperatura, validando se o valor informado é numérico e maior que 0°C.
* Recebe e processa leituras de temperatura, permitindo o encerramento manual do monitoramento.
* Calcula a média das temperaturas registradas e identifica os valores máximo e mínimo.
* Contabiliza a quantidade de leituras que ultrapassam o limite estabelecido.
* Emite alertas quando são detectadas temperaturas acima do limite de segurança.
* Realiza o desligamento automático do monitoramento após três leituras consecutivas acima do limite.

### 💻 Conceitos aplicados

* Linguagem C.
* Estruturas de repetição: `while` e `do-while`.
* Estruturas condicionais: `if`, `else` e `break`.
* Validação de entradas com `scanf`.
* Variáveis, contadores e acumuladores.
* Operações matemáticas e processamento de dados.
* Implementação de condições de segurança.

### 🎯 Objetivo

Consolidar os conhecimentos adquiridos na disciplina de Estruturas de Repetição, desenvolvendo uma aplicação prática que simula o monitoramento de temperaturas em um ambiente industrial.
